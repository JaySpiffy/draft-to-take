# Tutorial 04 - Judge, Retry, And Export

## Viewer Goal

The viewer understands the review loop: judge takes, retry weak unlocked lines, lock good lines, preview the timeline, and export the final mix.

Target length: 3 to 4 minutes.

## Screen Recording Shot List

1. Open a scene with generated dialogue.
2. Click `Judge Takes`.
3. Show pass, review, and retry/regenerate badges if available.
4. Lock one good take.
5. Retry weak unlocked takes.
6. Preview the mix.
7. Export or download the mix.
8. Show the output folder or downloaded file.

## Key Points To Say

- Judge Takes is a triage helper, not a replacement for listening.
- Lock good takes before batch retry.
- Retry Bad Takes should preserve locked/passing lines.
- Always preview before export.
- Export creates the final mix from the timeline.

## Recording Checklist

- Do not imply the automatic judge guarantees quality.
- Show at least one locked line.
- Show preview before export.
- Show the final exported file or browser download.
- Keep private project paths and personal filenames out of frame.
