# Tutorial 02 - Use That Voice In Script Canvas

## Viewer Goal

The viewer writes a tiny script, assigns a readable speaker label to a prepared voice, places the line on the timeline, and generates dialogue.

Target length: 3 to 4 minutes.

## Screen Recording Shot List

1. Open `Studio -> Script Canvas`.
2. Type a two-line demo script.
3. Show the voice assignment prompt or Voice Browser.
4. Open the Voice Workbench.
5. Assign `Mara` to a prepared voice.
6. Place the active scene.
7. Generate audio.
8. Play the generated line.

## Demo Script To Type On Screen

```text
Mara: Did you hear that?
Mara: The door sounded like it moved by itself.
```

## Key Points To Say

- Script labels can stay readable.
- Voice assignment is done in the Voice Workbench.
- You can write `Mara`, `Jonas`, or `Narrator` even when your voice file has a different name.
- Place the scene before generating.
- Generate audio after all visible roles have prepared voices.

## Script Canvas Narration

Paste this into Script Canvas and assign `Tutorial Narrator` to your narrator voice.

```text
Tutorial Narrator: Now we will use a prepared voice inside Script Canvas.
Tutorial Narrator: Open Studio, then open Script Canvas.
Tutorial Narrator: Script Canvas reads simple speaker lines, written as speaker, colon, spoken text.
Tutorial Narrator: I will write two short lines for a role named Mara.
Tutorial Narrator: Mara is a readable script role. It does not have to be a voice filename.
Tutorial Narrator: When Draft to Take sees an unassigned role, open the Voice Workbench.
Tutorial Narrator: Pick the role Mara on the left, then assign a prepared voice from the library.
Tutorial Narrator: This mapping tells the app which real voice should speak Mara's lines.
Tutorial Narrator: Once the role is assigned, place the active scene on the timeline.
Tutorial Narrator: Now press Generate Audio.
Tutorial Narrator: Draft to Take renders the dialogue with IndexTTS2 and keeps the clip linked to the script line.
Tutorial Narrator: Press Play on the line or the timeline to hear the result.
Tutorial Narrator: That is the core loop: write a line, assign a voice, place it, and generate.
```

## Recording Checklist

- Keep the script short enough to fit on screen.
- Show the Voice Workbench clearly.
- Show that the role name and prepared voice can be different.
- Play one generated line before ending.
