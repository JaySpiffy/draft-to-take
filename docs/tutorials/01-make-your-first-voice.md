# Tutorial 01 - Make Your First Voice

## Viewer Goal

The viewer finishes with one reusable prepared voice in the Voice Library and understands that voices are assets they can assign later in Script Canvas.

Target length: 2 to 3 minutes.

## Screen Recording Shot List

1. Open Draft to Take from the Start Menu or browser.
2. Open `Voices`.
3. Show the `Create Voice`, `Voice Library`, and `Source Clips` tabs.
4. Create a simple synthetic voice if OmniVoice is available, or import/prepare a source clip if using a local audio file.
5. Name the voice clearly.
6. Play the voice from the library.
7. Show the library metadata and confirm it is ready for Script Canvas.

## Key Points To Say

- A voice is a reusable audio asset.
- The script can use readable role names later.
- You do not need to rename a story character to a filename.
- Good voice names make large libraries easier to search.
- The Voice Workbench maps script roles to prepared voices.

## Script Canvas Narration

Paste this into Script Canvas and assign `Tutorial Narrator` to your narrator voice.

```text
Tutorial Narrator: In this first video, we will make one reusable voice for Draft to Take.
Tutorial Narrator: A prepared voice is the sound source Script Canvas can use later.
Tutorial Narrator: Start on the Home page, then open Voices from the sidebar.
Tutorial Narrator: The Voices page keeps creation, source clips, and the voice library in one place.
Tutorial Narrator: If OmniVoice is available, choose Create Voice and pick a simple preset.
Tutorial Narrator: If you already have audio, use Source Clips and prepare a clean speaker sample.
Tutorial Narrator: Give the voice a clear name, so you can find it again later.
Tutorial Narrator: Names like calm narrator or bright podcast host are easier to browse than random filenames.
Tutorial Narrator: After the voice appears in the library, press Play and listen to it.
Tutorial Narrator: If it sounds useful, keep it. If it sounds noisy or weak, prepare a better source clip.
Tutorial Narrator: This voice is now ready for Script Canvas.
Tutorial Narrator: In the next video, we will assign it to a script role and generate a spoken line.
```

## Recording Checklist

- Show that the installer version can open the app.
- Do not show private voice samples or personal files.
- Keep the source clip short and safe for public viewing.
- Let the first voice preview visibly load if it takes a second.
- End with the prepared voice visible in the library.
