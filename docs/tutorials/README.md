# Draft to Take Tutorial Series

This folder is a production kit for short public tutorial videos.

The goal is to show the normal beginner path without making one long video:

1. Make your first voice.
2. Use that voice in Script Canvas.
3. Add SFX, ambience, and music.
4. Judge, retry, lock, and export.

Each tutorial has:

- a viewer goal
- a short running time target
- a screen recording shot list
- a Script Canvas-ready narration script
- a matching checklist for recording and editing

## Recommended Production Workflow

1. Open Draft to Take.
2. Create or choose one clear voice for the tutorial narrator.
3. Open `Studio -> Script Canvas`.
4. Paste the narration script from the tutorial file.
5. Assign `Tutorial Narrator` to the prepared narrator voice in the Voice Workbench.
6. Place the scene on the timeline.
7. Generate audio with IndexTTS2.
8. Judge takes, retry weak takes, and lock the clean takes.
9. Export the narration mix.
10. Record the matching screen steps.
11. Edit screen recording plus exported narration into a short video.

Keep each finished video under five minutes. The viewer should finish one useful workflow, not memorize every button in the app.

## Series Voice Labels

Use these labels in the narration scripts:

```text
Tutorial Narrator
Mara
Jonas
```

`Tutorial Narrator` is the voiceover. `Mara` and `Jonas` are simple demo script roles. They do not need to match prepared voice filenames because the Voice Workbench can assign readable roles to prepared voices.
